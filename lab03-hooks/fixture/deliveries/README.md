Записанные доставки вебхука GitHub.

Каждая пара файлов: `<имя>.json` — тело запроса ровно теми байтами, что пришли,
`<имя>.sig` — значение заголовка `X-Hub-Signature-256` этой доставки.

Секрет вебхука для всех примеров: `opr-2026-secret`

| Доставка | Что это |
|---|---|
| `push-valid` | обычный push, подпись верная |
| `pr-valid` | открытие pull request, подпись верная |
| `pr-tampered` | тело подменили после подписания |
| `push-wrong-secret` | подпись сделана чужим секретом |
