Задача 15. Склад книжного магазина
Сдавать: файл 15.sh. Аргументы приходят в $1, $2…; вывести одну строку — ровно ответ.

У книготорговца есть список «КОД количество»; первая буква кода — категория книги (A–Z).
Даны список позиций и список категорий. Для каждой категории из второго списка посчитать,
сколько всего книг этой категории на складе, и вывести в формате
«(A : 20) - (B : 114) - ...» в порядке категорий. Если какой-то из списков пуст — пустая строка.

Два аргумента, элементы внутри разделены запятыми.

Пример:
./15.sh "BBAR 150,CDXE 515,BKWR 250,BTSQ 890,DRTY 600" "A,B,C,D"
(A : 0) - (B : 1290) - (C : 515) - (D : 600)
