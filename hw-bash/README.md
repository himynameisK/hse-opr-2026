# Домашка по bash

У каждого одна задача — номер вам назовёт преподаватель. Дальше всё про неё,
на примере задачи 8.

### DEADLINE 01.12.2026

## Как решать

1. Прочитайте условие: `8.txt` (у некоторых задач — `8_hard.txt`).
   В начале файла написано, как запускается решение и что именно оно должно напечатать.
2. Напишите решение в файл `8.sh` в этой же папке и сделайте его исполняемым:
   `chmod +x 8.sh`.
3. Проверьте:

   ```
   ./check.sh 8
   ```

   В конце будет «Можно сдавать 8.sh» или список тестов, которые не прошли:
   с какими аргументами запускалось, что ожидалось и что напечатало ваше решение.
4. Сдайте один файл — `8.sh`.

При сдаче решение проверят на большем числе тестов, чем в `tests/8.sh`:
другие входы, крайние случаи и, где это указано в условии, большой вход с лимитом времени.

## Требования к решению

- первая строка — шебанг: `#!/usr/bin/env bash`;
- входные данные приходят аргументами: `$1`, `$2`, …;
  строку с пробелами при запуске берут в кавычки: `./3.sh "Hello, World!"`;
- скрипт печатает **одну строку — ровно ответ**, как в примерах из условия: без пояснений,
  без лишних пробелов и пустых строк. Отладку печатайте в stderr: `echo "x=$x" >&2`.

## Где писать

Пишите так, как принято в Linux: bash 5, GNU coreutils, `sed`, `grep`, `awk`, `bc` —
всё, что есть в обычной Ubuntu, использовать можно. Проверка запускает решения
в таком же окружении с локалью `LC_ALL=C`: `sort` сортирует по кодам символов
(`B` раньше `a`), строки обрабатываются побайтно.

- **Linux** — всё уже есть.
- **Windows** — WSL (Ubuntu) или Git Bash. Сохраняйте файлы с окончаниями строк LF:
  с CRLF скрипт падает с ошибкой `$'\r': command not found`.
- **macOS** — встроенный bash там 2007 года (3.2), а утилиты не GNU. Поставьте:
  `brew install bash coreutils gnu-sed grep gawk` — `check.sh` подхватит их сам.
