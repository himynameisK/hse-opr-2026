Задача 10. docker logs молчит

Сервис приёма заказов ведёт журнал.

  docker build -t opr11-logs .
  docker run -d --rm --name opr11-logs -p 8080:8000 opr11-logs
  curl "http://localhost:8080/order?id=42"          заказ 42 принят
  docker logs opr11-logs                            (пусто)

Журнал есть, но его не видно ни в docker logs, ни в системе сбора логов,
которая читает их у Docker. Чтобы что-то узнать, приходится заходить
в каждый контейнер: docker exec … cat …, а когда контейнер удалён —
журнал пропадает вместе с ним, да и растёт он внутри контейнера без ограничений.

Нужно:
  - строки журнала («заказ 42 принят» и прочие) видны в docker logs сразу,
    без захода в контейнер;
  - контейнер, как и раньше, останавливается по docker stop быстро
    и с кодом 0.
Менять можно: Dockerfile. Нельзя: app.py.
Проверить: python3 check.py 10
