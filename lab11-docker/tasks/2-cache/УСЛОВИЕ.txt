Задача 2. Каждая сборка ставит зависимости заново

Ведомость оценок печатает таблицу с помощью пакета tabulate из requirements.txt.

  docker build -t opr11-cache .
  docker run --rm opr11-cache

Работает. Но поправьте в app.py одну букву и соберите ещё раз с подробным выводом:

  docker build --progress=plain -t opr11-cache .

pip снова пишет Collecting tabulate… Downloading… Successfully installed — на каждой
правке кода. Здесь пакет один и маленький; в настоящем проекте их сотня, и каждая
сборка ждёт по пять минут.

Нужно:
  - после правки кода (app.py) пересборка не ставит зависимости: этот шаг CACHED;
  - после правки requirements.txt зависимости ставятся заново, именно те версии,
    что в файле;
  - образ, как и раньше, печатает ведомость с правильной версией.
Менять можно: Dockerfile, можно добавить .dockerignore. Нельзя: app.py, requirements.txt.

Как проверяет check.py: в своей копии каталога собирает без кеша, меняет
REPORT_VERSION в app.py, пересобирает, затем меняет версию tabulate в
requirements.txt и пересобирает ещё раз. Нужен интернет: пакет ставится с PyPI.
Проверить: python3 check.py 2
