Задача 4. Токен утёк вместе с образом

Сервис каталога. Токен к закрытому хранилищу нужен дважды: при сборке
(prepare.py скачивает каталог) и при работе (app.py ходит в хранилище).

  docker build --build-arg API_TOKEN=tok-123 -t opr11-secret .
  docker run -d --rm -p 8080:8000 opr11-secret
  curl http://localhost:8080/

Всё работает. Но образ ушёл в реестр, и безопасник любого, у кого есть
docker pull, попросил выполнить:

  docker history --no-trunc opr11-secret
  docker image inspect opr11-secret

и показал вам ваш токен. Токен пришлось отзывать.

Нужно:
  - токена нет в образе: ни в docker history, ни в docker image inspect,
    ни в одном файле любого слоя;
  - при сборке prepare.py всё так же получает токен и скачивает каталог;
  - при запуске токен передаётся снаружи, и сервис отвечает.
Менять можно: Dockerfile. Нельзя: prepare.py, app.py.

Конвейер (и check.py) менять нельзя, он делает ровно так, с разными токенами
на сборку и на запуск:
  при сборке передаёт токен двумя способами сразу —
    docker build --build-arg API_TOKEN=… --secret id=api_token,env=… .
  при запуске —
    docker run -e API_TOKEN=… образ
Пользоваться можно любым из способов сборки — тем, который не оставляет следов.
Проверить: python3 check.py 4
