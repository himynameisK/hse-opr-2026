Задача 5. Маленький сервис в огромном образе

pinger — сервис на Go, отвечает на GET /ping.

  docker build -t opr11-pinger .
  docker run -d --rm -p 8080:8080 opr11-pinger
  curl http://localhost:8080/ping                   pong 1.4.2
  docker images opr11-pinger

Сам бинарник — несколько мегабайт, а образ весит сотни. Его тянут на каждый
сервер при каждой выкладке, и в нём лежит компилятор Go со всеми исходниками
стандартной библиотеки, хотя запускать там нужно только готовую программу.

Нужно:
  - содержимое образа меньше 30 МБ (check.py считает сумму размеров файлов
    из docker export — так одинаково на любой машине);
  - в итоговом образе нет компилятора go;
  - сервис по-прежнему отвечает «pong 1.4.2».
Менять можно: Dockerfile, можно добавить .dockerignore. Нельзя: main.go, go.mod.
Базовые образы — закреплённые теги: golang:1.23-alpine, alpine:3.20 (или scratch).
Проверить: python3 check.py 5
